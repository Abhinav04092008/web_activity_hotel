
# Grand Horizon - Hotel Booking Website

## 1. Project Description
Grand Horizon is a modern and responsive hotel booking website developed using HTML and CSS. It provides information about hotel rooms, facilities, prices, special offers, customer reviews, and booking options.

## 5. Features
- Modern and attractive user interface
- Hotel room cards with images and prices
- Booking form with check-in and check-out fields
- Guest and room selection options
- Hotel facilities information
- Customer review section
- Responsive design for desktop and mobile screens
- Smooth navigation and hover effects
